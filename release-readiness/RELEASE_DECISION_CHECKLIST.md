# Release Decision Checklist

## Required Before Marking GitHub Release Ready

- [x] Remote branch pushed.
- [x] Required phase tags visible remotely.
- [x] `release-handoff-phase-0-3.8` visible remotely.
- [x] GitHub Actions release gate green.
- [x] Handoff package committed.
- [ ] Release notes reviewed.
- [ ] Remaining risks accepted.
- [x] Production deployment explicitly excluded from this release.

## Optional Before Production

- [ ] Production readiness review completed.
- [ ] Secrets/config review completed.
- [ ] Deployment topology chosen.
- [ ] Rollback procedure tested.
